## 项目简介

基于 Qt 6 Widgets 的 C++ 桌面应用，实现学生信息的增删改查、登录鉴权（管理员/普通用户）、
年龄分布数据可视化（Qt Charts）、模拟数据生成等功能，采用 SQLite 嵌入式数据库存储。

默认登录账号：`张三` / `123456`（当年和豆包约定的测试账号，一直保留至今）。

## 技术栈

- Qt 6.10 / C++17（MinGW 64-bit）
- Qt Widgets（Model/View 架构展示学生列表）
- Qt Charts（年龄分布图表）
- SQLite（QSQLITE 驱动，免安装免配置）
- Qt 资源系统（.qrc）+ Qt 样式表（界面背景与配色）

## 目录结构

```
stumr.pro      Qt 工程文件
main.cpp       入口
login.*        登录窗口
mainwindow.*   主窗口（学生列表 + 增删改查入口）
view.*         查看界面
dlg_addst.*    添加学生对话框
dlg_change.*   修改学生对话框
stusql.*       SQLite 数据访问层（单例）
res.qrc        Qt 资源清单（界面背景图）
data.db        SQLite 数据库（含测试数据）
1.jpg ~ 8.jpg  界面背景素材
```

## 运行方式

1. 用 Qt Creator 打开 `stumr.pro`，选择 Desktop Qt 6.x MinGW 64-bit 套件；
2. 构建并运行；
3. `data.db` 需与可执行文件位于同一目录（代码中使用 `applicationDirPath()` 定位）。

## 测试数据说明
